Why not a detector

Nobody wants a verdict.
They want a lever.

When the "Ask HN: Add flag for AI-generated articles" thread hit 1,100 points, the answer from platforms was a policy debate. Meanwhile readers were already building their own killfiles and extensions. That demand is what FeedCull is built on — the proper version of the workaround.

AI detection is unreliable, and false accusations hurt real people. So FeedCull never says "this is AI." It surfaces pattern signals, and the decision is always yours — killfiles and topic filters are exact, and the heuristic scorer is a knob you set, not a judge that sets you.

Private by design: no accounts, no tracking, no servers. Everything runs locally in your browser. There is nothing to sell, which is exactly the point.

Built by its own test suite. While developing the scorer, the automated install test caught a substring bug: the keyword "ai" was hiding There Will Come Soft Rains — the "ai" hiding inside Rains — and "failed" was getting culled for the same reason. Word-boundary matching fixed both. No Rains were culled. The test harness stays in the repo and runs on every change.

FAQ

Straight answers.

What's the difference between Free and Pro right now?

Today, v0.1.2's Free and Pro are functionally identical — the Pro features (article-text judging, sync, all sites) are phase-2 work that isn't built yet. Buying Pro now is a pre-order: you lock in the price, fund the build, and get first access when it ships. That's also why the first 500 waitlist members get Pro free forever — early believers shouldn't pay for what they're helping build.

Is this an AI detector?

No — deliberately. Detection is unreliable, and false accusations hurt real people. FeedCull shows you pattern signals and hands you the lever: killfiles and topic filters are exact, the heuristic scorer is a sensitivity knob you control. It never issues a verdict.

What data leaves my machine?

None. No accounts, no tracking, no servers. Settings live in your browser's storage, scoring runs locally, and there is no telemetry. The only optional network call is the phase-2 Pro LLM-judge — and it will be explicit, never implicit.

Why load unpacked instead of the Chrome Web Store?

Speed — the store review takes weeks and this shipped in a day. The install is a 60-second "Load unpacked" from the repo zip; the store listing follows once the Reddit adapter passes its live test. Same extension either way.
